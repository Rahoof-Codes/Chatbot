A mobile-first AI chatbot built with Next.js, Firebase, and OpenRouter API.

## 💡 What This Project Does

This is a fully working AI chatbot web app where:

- You **login with your Google account**
- You can **chat with an AI** that replies in real time (word by word)
- Your **chat history is saved** — come back tomorrow and it's still there
- You can **start multiple chats** and switch between them
- Works perfectly on **mobile phones** 📱

---

## 🛠️ Built With

| Tool | Why I used it |
|---|---|
| **Next.js 15** | Main framework — handles both frontend and backend |
| **React 19** | Builds the UI components |
| **TypeScript** | Catches errors before they happen |
| **Tailwind CSS 4** | Makes the UI look good quickly |
| **Firebase Auth** | Google login — no need to build auth from scratch |
| **Firestore** | Saves chat history to the cloud |
| **OpenRouter API** | Gives access to free AI models |
| **Lucide React** | Clean icons (send button, menu, trash, etc.) |
| **React Markdown** | Renders AI responses with proper formatting |
